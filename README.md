# CryptoAI 自動交易系統 v2.0

基於 Binance USDT-M Futures 的自動化交易機器人，實現完整混合策略。

## 功能特點

### 完整混合出場策略
- **固定止損**: 虧損達 5 USDT 立即平倉
- **移動止損**: 獲利 30 USDT 以上啟動，動態保護利潤
- **分批出場**: +50%/100%/150%/200% 各減持 25%
- **時間止損**: 持倉超過 4 小時且無顯著獲利時減持
- **技術出場**: 成交量萎縮或趨勢反轉時提前出場

### 選幣邏輯
- 24 小時漲幅 ≥ 20%
- 24 小時成交量 ≥ 1,000,000 USDT
- 評分權重：40% 價格變化 + 40% 成交量 + 20% 市場排名

### 交易特性
- 支援 Binance 測試網和正式網
- 最大同時持倉 3 個
- 10 倍槓桿
- 每分鐘自動檢查市場

## 安裝步驟

### 1. 安裝依賴

```bash
pip install -r requirements.txt
```

### 2. 取得 API Key

1. 登入 [Binance](https://www.binance.com)
2. 進入「個人中心」→「API 管理」
3. 建立新的 API Key
4. 啟用「合約交易」權限
5. 建議設定 IP 白名單增加安全性

### 3. 配置設定檔

編輯 `config.yaml` 調整參數：

```yaml
trading:
  max_position: 3        # 最大持倉數
  leverage: 10           # 槓桿倍數
  stop_loss: 5           # 固定止損 (USDT)
  check_interval: 60     # 檢查間隔 (秒)
  
  # 移動止損
  trailing_stop_enabled: true
  trailing_stop_trigger_pnl: 30
  
  # 時間止損
  time_stop_enabled: true
  time_stop_max_minutes: 240
```

## 策略說明

### 出場優先級

1. **固定止損** (最高) - PnL ≤ -5 USDT
2. **移動止損** - 保護既有利潤
3. **技術出場** - 趨勢反轉訊號
4. **時間止損** - 避免資金效率低落
5. **分批出場** - 獲利了結
6. **全數止盈** - 最終目標

### 移動止損規則

| PnL 區間 | 止損方式 |
|---------|---------|
| 30-100 USDT | 保留 2% 緩衝 |
| 100-150 USDT | 保留 5% 緩衝 |
| > 150 USDT | 從最高點回撤 5% |

### 分批出場配置

```yaml
scaling_out:
  50: 0.25   # +50% → 減持 25%
  100: 0.25  # +100% → 減持 25%
  150: 0.25  # +150% → 減持 25%
  200: 0.25  # +200% → 減持 25%
```

## 風險提示

⚠️ **重要提醒**

1. **測試網優先**: 建議先在測試網熟悉運作
2. **小額測試**: 正式上線前先用最小金額測試
3. **API 安全**: 不要洩露 API Key，建議設定 IP 白名單
4. **槓桿風險**: 10 倍槓桿會放大 10 倍損益
5. **市場風險**: 加密貨幣波動劇烈，可能快速觸發止損
6. **技術風險**: API 延遲或故障可能影響交易執行

## 常見問題

### Q: 為什麼訂單無法建立？
A: 檢查以下幾點：
- API Key 是否有「合約交易」權限
- 帳戶餘額是否充足
- 交易對是否正確（需為 USDT 結算）
- 是否有 IP 白名單限制

### Q: 如何查看交易記錄？
A: 所有交易會記錄到 `trades.csv` 檔案

### Q: 如何調整參數？
A: 編輯 `config.yaml` 後重新啟動程式

### Q: 測試網和正式網差在哪？
A: 測試網使用虛擬資金，正式網使用真實資金。請謹慎選擇。
